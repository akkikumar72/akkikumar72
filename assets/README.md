## Walkthrough Studio

The featured frame comes from an iteratively refined reconstruction of **Noaks väg 3B**. **Courtyard House** is a separate fictional workspace demo. Neither the still nor the refined example establishes automatic photorealistic reconstruction from arbitrary listings.

The project's source listing photography is credited to **Jean Vanrop / Vanrop Photography**. Retain that credit when reusing assets containing source-photo comparisons or listing imagery. Third-party photography remains separate from the source-code license; this document does not grant new rights to it.

The square portfolio cover is generated presentation artwork. It is not used in this README. The featured landscape image is an actual Three.js film frame, not that generated cover.

## Updating the gallery

1. Use an existing, publishable project image. Copy it into `projects/` and preserve its proportions. Keep full-resolution working files and private information out of this public repository.
2. Update the linked image, descriptive alt text, one-sentence description, and public destinations in the root README. Keep the title and description as text rather than baking them into a new image.
3. Add its source and any required attribution here. Distinguish product captures, rendered scenes, and generated presentation artwork.
4. Update the project catalog too. Check repository visibility and deployed URLs without authentication. Leave out private source links and localhost or unavailable deployments.
5. Inspect GitHub's rendered README on desktop and phone in light and dark themes, then run `git diff --check` before opening a PR. This repository has no build pipeline or automated CI checks.
